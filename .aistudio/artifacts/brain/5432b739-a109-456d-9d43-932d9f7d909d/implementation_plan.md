# 车床端面燕尾槽轮廓切点可视化系统 (Lathe Face Dovetail Groove CAD Visualizer)

一套专为机械加工与数控车削工程师打造的**标准对称梯形端面燕尾槽 CAD 几何轮廓与切点精确解算可视化工具**。通过参数化驱动与纯解析几何引擎，实时绘制端面燕尾槽剖面 CAD 轮廓、理论交点、圆弧过渡切点及标准工程标注。

## User Review & Critical Decisions

> [!IMPORTANT]
> 以下为根据您的偏好确认的核心范围与关键架构决策：

- **确认决策 1 — 几何模型范围**：采用**标准对称梯形端面燕尾槽**参数化模型，涵盖中心基准直径（或外径/内径基准）、开口宽度 ($W_{\text{open}}$)、底宽 ($W_{\text{bottom}}$)、槽深 ($H$)、两侧对称燕尾角 ($\alpha$) 以及槽口/槽底过渡圆弧半径 ($R_1, R_2$)，用于精确计算与展示轮廓切点。
- **确认决策 2 — 视图与呈现方式**：**仅显示纯净的 CAD 工程轮廓与几何切点**，不引入刀具模型或走刀仿真。专注于高对比度 CAD 工程制图视口、相切节点 ($T_n$)、理论尖角交点 ($V_n$)、圆弧圆心 ($O_n$) 及尺寸/角度引线标注。
- **确认决策 3 — 精简辅助功能**：不添加 G 代码生成、DXF 导出或碰撞仿真等外围功能，确保界面聚焦于核心几何关系与切点坐标的直观验证。
- **工程设计决策 — 梯形过约束参数的联动解算模式**：在对称梯形几何中，开口宽度 $W_{\text{open}}$、底宽 $W_{\text{bottom}}$、槽深 $H$ 与燕尾斜面角度 $\alpha$ 四者存在三角函数几何约束关系（$W_{\text{bottom}} = W_{\text{open}} + \frac{2H}{\tan\alpha}$）。系统提供**参数驱动模式切换**（默认以「开口宽 + 槽深 + 燕尾角 → 自动解算底宽」，可一键切换为「开口宽 + 底宽 + 槽深 → 自动反算燕尾角」），避免输入几何矛盾。

## 1. Overview & Core Concept

- **核心功能**：输入端面燕尾槽的设计图纸尺寸，实时通过三角解析几何计算出端面基准线、两侧内倾燕尾斜壁、槽底平面以及槽口/槽底过渡圆弧的**精确切点坐标 $(X, Z)$**，并在可缩放平移的 CAD 工程画布中直观渲染。
- **目标用户**：数控车床工艺员、CAD/CAM 编程工程师、精密机械设计人员。
- **核心价值**：消除手工三角函数计算端面燕尾槽斜壁过渡切点的繁琐与易错性，以优雅的工程级 CAD 视图实时反馈每一个几何切点、圆弧圆心与轮廓段关系。

## 2. User Experience & Visual Design

- **核心交互流程**：
  1. **参数设定与约束联动**：用户在右侧参数面板调节燕尾槽核心尺寸（中心直径 $D_c$、开口宽 $W_1$、底宽 $W_2$、槽深 $H$、燕尾角 $\alpha$、槽口圆角 $R_{\text{top}}$、槽底圆角 $R_{\text{bottom}}$）。当修改任一参数时，受几何方程约束的从属参数实时同步更新，并校验几何合法性（如圆角过大导致斜壁直线段消失时的超限提示）。
  2. **CAD 视口观察与图元交互**：左侧主画布（占比 70%）实时渲染端面燕尾槽的轴向剖面图（X-Z 车床坐标系）。支持滚轮缩放、拖拽平移、一键复位视图，以及图层显示开关（切点标记、理论交点虚线、圆心十字、尺寸标注线、坐标网格）。
  3. **切点拾取与坐标核对**：鼠标悬停或点击 CAD 轮廓上的任意切点（如槽口圆弧起点 $T_1$、槽口圆弧与燕尾斜壁切点 $T_2$、斜壁与槽底圆弧切点 $T_3$、槽底圆弧终点 $T_4$），画布高亮对应切线法向量与圆弧半径连线，并在状态面板聚焦显示该点的车床直径值 $X$（支持直径/半径制显示）与轴向深度 $Z$。

- **视觉风格与主题定义 (Visual Identity & Theme)**：
  - *美学方向*：精密工业 CAD 蓝图风格（Precision Industrial CAD Blueprint），遵循 `frontend-design` 交互仿真规范，采用「左主画布 (70%) + 右控制面板 (30%)」的双区沙盒布局。
  - *色彩体系 (60-30-10 原则)*：
    - **60% 主画布背景**：深邃工业石板蓝黑（`#0B1120` / `slate-950`），搭配微弱的自适应工程坐标网格线（`#1E293B`），突出亮色 CAD 轮廓图元。
    - **30% 结构面板与标尺**：右侧控制区采用沉稳的深灰蓝表面（`#0F172A` / `slate-900`）与 `1px` 细线分割（`#1E293B`），杜绝嵌套卡片与厚重左边框。
    - **10% 语义化工程图元强调色**：
      - 实线 CAD 轮廓：高对比工程白/青蓝（`#38BDF8` / `sky-400`）
      - 几何切点 ($T_n$)：精密琥珀黄（`#F59E0B` / `amber-400`）配实心靶标与文字标签
      - 过渡圆弧与圆心 ($O_n$)：翡翠绿（`#10B981` / `emerald-400`）配虚线法向半径线
      - 理论尖角延长线与尺寸标注：柔和板岩灰（`#94A3B8` / `slate-400`）
      - 几何超限/过切告警：珊瑚红（`#EF4444` / `red-500`）配明确文字说明
  - *字体与数字排版*：
    - 标题与界面文案：`Plus Jakarta Sans`，清晰现代。
    - 坐标、角度与尺寸数值：全局强制使用等宽字体 `JetBrains Mono` 并开启 `tabular-nums`，确保小数点后三位（`0.001 mm`）在实时滑动调节时垂直对齐、零抖动。

## 3. Key Product Decisions & Trade-Offs

- **决策 1：严格的逻辑分层与模块化架构（响应架构优雅性要求）**
  - *选定方案*：将应用严格划分为四层独立模块：**领域类型层 (`types`)**、**纯数学几何解算层 (`domain/geometry`)**、**状态与约束校验层 (`hooks`)**、**CAD 渲染与控件视图层 (`components`)**。
  - *原因*：几何切点计算涉及大量半角正切/余切公式与车床 X/Z 坐标转换。将数学计算封装为纯函数并定义严谨的几何图元数据结构，不仅保证 100% 可测试与零副作用，而且便于未来扩展单斜角燕尾槽或刀具偏置算法时无需改动渲染层。
- **决策 2：使用高精度矢量 SVG 构建 CAD 工程图视口**
  - *选定方案*：采用基于世界坐标到屏幕视口变换矩阵（World-to-Screen Transform）的定制 SVG 矢量画布，支持无损缩放与图元级悬停拾取。
  - *原因*：相比位图 Canvas，SVG 对 CAD 直线段、圆弧路径（`A` 指令）、虚线延长线、箭头尺寸标注以及单点 Hover/Click 事件具备原生 DOM 级高精度响应，放大至局部微米级圆角切点时依然保持边缘锐利。

### 核心数据模型与几何数学解算逻辑

1. **核心领域数据类型 (`types/geometry.ts`)**：
   - `DovetailDriveMode`: `'angle_driven'`（输入开口宽、槽深、燕尾角 → 推导底宽） | `'width_driven'`（输入开口宽、底宽、槽深 → 推导燕尾角）。
   - `DovetailParameters`: 包含基准中心直径 $D_{\text{center}}$、开口宽度 $W_{\text{open}}$、底部宽度 $W_{\text{bottom}}$、槽深 $H$、单侧燕尾角 $\alpha$（与端面的夹角，锐角，通常 $45^\circ \sim 75^\circ$）、槽口过渡圆角 $R_{\text{top}}$、槽底过渡圆角 $R_{\text{bottom}}$。
   - `KeyGeometricPoint`: 统一封装关键几何点，含唯一标识 `id`（如 `T_L1`, `T_L2`, `V_L_TOP`, `O_L_TOP`）、点类型（`'tangent'` 切点 | `'vertex'` 理论交点 | `'center'` 圆弧圆心）、笛卡尔局部坐标 $(x, z)$、车床编程坐标 $(X_{\text{diam}}, X_{\text{rad}}, Z)$ 及所属几何段描述。
   - `ContourPrimitive`: 区分 `'line'`（端面直壁、燕尾斜壁、槽底平面）与 `'arc'`（槽口圆弧、槽底圆弧，含起止角、半径与顺逆时针方向），供 CAD 画布直接遍历渲染。

2. **对称梯形端面燕尾槽切点解析公式 (`domain/dovetailSolver.ts`)**：
   - 设端面为 $Z = 0$（槽深方向为 $-Z$），燕尾槽截面中心对称轴位于半径 $R_c = D_{\text{center}} / 2$，燕尾斜壁与端面夹角为锐角 $\alpha \in (0^\circ, 90^\circ)$：
   - **理论尖角交点 (Theoretical Sharp Vertices)**：
     - 槽口左右尖角点：$V_{\text{top}} = (\pm \frac{W_{\text{open}}}{2}, 0)$
     - 槽底左右尖角点：$V_{\text{bottom}} = (\pm \frac{W_{\text{bottom}}}{2}, -H)$，其中 $\frac{W_{\text{bottom}} - W_{\text{open}}}{2} = H \cdot \cot\alpha$
   - **槽口圆弧 ($R_{\text{top}}$) 切点与圆心解算**：
     - 槽口處端面与内倾燕尾斜壁的实体内夹角为 $\theta_{\text{top}} = \alpha$（锐角），圆弧半角偏移距为 $L_{\text{top}} = \frac{R_{\text{top}}}{\tan(\alpha / 2)}$。
     - 端面上的切点 $T_1$：距尖角点向槽外偏移 $L_{\text{top}}$。
     - 燕尾斜壁上的切点 $T_2$：自尖角点沿斜壁向下偏移 $L_{\text{top}}$，即 $\Delta x = \pm L_{\text{top}} \cos\alpha$，$\Delta z = -L_{\text{top}} \sin\alpha$。
   - **槽底圆弧 ($R_{\text{bottom}}$) 切点与圆心解算**：
     - 槽底平面与燕尾斜壁的内夹角为 $\alpha$，圆弧切线偏移距为 $L_{\text{bottom}} = \frac{R_{\text{bottom}}}{\tan(\alpha / 2)}$。
     - 斜壁上的下切点 $T_3$：自槽底尖角点沿斜壁向上回退 $L_{\text{bottom}}$。
     - 槽底平面上的切点 $T_4$：自槽底尖角点向槽中心偏移 $L_{\text{bottom}}$。
   - **几何干涉与退化校验**：
     - 斜壁总长度 $S_{\text{wall}} = \frac{H}{\sin\alpha}$。当 $L_{\text{top}} + L_{\text{bottom}} > S_{\text{wall}}$ 时，槽口圆弧与槽底圆弧在斜壁上发生过切重叠，解算器立即标记异常状态并在画布中高亮提示。
